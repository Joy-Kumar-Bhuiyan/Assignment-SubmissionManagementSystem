# Resume notes

## One-line project description

Role-based assignment and submission platform built with ASP.NET Core, EF Core, PostgreSQL, React, JWT authorization, audit reporting, and tested external integrations.

## Four resume bullets

- Built and secured REST APIs for Admin, Teacher, and Student assignment workflows using ASP.NET Core, EF Core, PostgreSQL, JWT claims, allocation checks, and object-level ownership rules.
- Added a persistent audit trail and role-aware dashboard using database-side LINQ filtering, grouping, counts, averages, pagination, and query-focused indexes.
- Integrated optional SMTP email and configuration-only outgoing webhooks with dependency injection, safe payloads, timeouts, mocked tests, and failure isolation from core grading/publishing transactions.
- Implemented JSON/XML assignment export and regression tests for cross-class access, invalid marks/statuses, deadlines, filtering, audit authorization, integration failures, and complete submit-to-grade flow; automated build, lint, dependency audit, and CodeQL checks in GitHub Actions.
